# Generic

Use `generic` for hosted, local, and self-hosted OpenAI-compatible Chat Completions
APIs. Neuralwatt, DeepInfra, SiliconFlow, and OrcaRouter can be configured with
their API base URL, API key, and model ID.

Follow [Hosted provider setup](additional.md#hosted-provider-setup) for a complete
configuration example and an endpoint reference, or see
[Local endpoints](additional.md#local-endpoints) for Ollama.

For separate credentials and endpoints per model, use
[Model Overlays](../model_overlays.md).
