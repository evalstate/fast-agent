Sentence-case action button; use one `primary` per view for the main CTA, `secondary` beside it, `ghost` for tertiary text actions.

```jsx
<Button variant="primary">Try it now</Button>
<Button variant="secondary">Read the docs</Button>
<Button variant="ghost" size="sm">Methodology</Button>
```

- Press drops the primary onto its amber ledge (no scale-down). Secondary fills amber on hover.
- Sizes: sm 13px, md 15px, lg 17px. Never tilt a button.
